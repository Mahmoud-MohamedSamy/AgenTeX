New bug · Skills | Skill types are one list shared by all departments; in Zoho each department has its own skill types

Priority: Medium · State: Bug · Label: Assignment Rules · Module: Desk · Cycle: Sprint 15 · Assignees: same three as NDC-2811..2814 · Relates to NDC-2752, NDC-2805

Summary

Skills are now set per department (NDC-2752), but skill types are still one list for the whole company. In Zoho Desk the Skill Types tab follows the department picker, so each department has its own skill types. In TAVI every department sees and changes the same list, and the page says so: “Every department uses the same types.”

Steps to Reproduce

  1. Sign in to TAVI Desk as an admin and go to Setup › Customization › Skills.
  2. Open the Skill Types tab.
  3. Look for a department picker. There is none, and the help text says “Every department uses the same types.”

Expected Result

  • Like Zoho Desk, the Skill Types tab follows the selected department, and each department has its own list of skill types.
  • Adding, renaming or deleting a skill type affects only that department.

Actual Result

  • The Skill Types tab has no department picker and shows one list (General, Tech, …) for every department.
  • The help text says “Every department uses the same types.”, while the page subtitle says “Define each department’s skills and skill types”.
  • Because there is one list, a type added, renamed or deleted for one department is the same for all departments.

Zoho Desk reference

  • Setup › Skills › Skill Types, org techsolutionsegypt: the department picker (Haytham Mohamed) sits at the top, and the Skill Types list with its associated skills belongs to that department. Seen 8 Nov 2026.
  • Not checked in Zoho: what another department sees after a type is added.
