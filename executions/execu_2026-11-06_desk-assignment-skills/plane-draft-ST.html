Description

Skill types are one list shared by every department. In Zoho Desk, skill types are managed per department, like skills. TAVI's skills are already per department, but their types are not.

Steps

  1. Go to Setup → Customization → Skills → Skills tab. Note the Department picker: skills belong to one department.
  2. Open the Skill Types tab.
  3. Look for a department picker, and read the help text above the list.

Expected

The Skill Types tab has the same department picker as the Skills tab, and each department has its own list of skill types, as in Zoho Desk (Setup → Skills → SKILL TYPES keeps the department picker; the list sits under the selected department).

Actual

  • The Skill Types tab has no department picker. Its help text says "Skill types group skills, such as Languages or Products. Every department uses the same types."
  • One list is shown for all departments (on NDC-Staging: General, Tech, QA AS6 Type, QA AS6 Type3). Every department sees and uses every type; a type cannot be limited to one department.
  • The API matches the screen: GET /desk/skill-types returns one list with no department.

Notes

  • Skills themselves are per department in TAVI (Skills tab has a Department picker), so only the types are affected.
  • Deleting a skill type that skills still use is refused in both products with a clear message. TAVI: "Skills still have this skill type. Give them another type first." Zoho: "The skill type could not be deleted because it is associated with one or more skills." That part works and is not part of this bug.
  • Zoho side: only department Haytham Mohamed was opened; other departments' lists were not compared.

Environment

Environment: staging-desk.taviportal.com, tenant NDC-Staging, owner account, Edge + API. Zoho Desk reference: org techsolutionsegypt, department Haytham Mohamed. Checked 8 Nov 2026.
