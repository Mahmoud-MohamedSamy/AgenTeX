New bug candidates

Not in Plane yet. They wait for approval at Gate 2.

W2-B4High

A deal can't be moved to another pipeline

Record page, Mass Update and API all fail with 422 "Invalid value for: Pipeline". The Pipeline field only allows "Standard (Standard)". No error on screen and the dialog stays open.

W2-B6Medium

Users on the "User" profile can't search

Global search says "You don't have access to search" (403). The built-in profile has no search permission; Zoho's Standard profile has it.

W2-B7Medium

"+ Task" on a record has no form

First open hangs on "Loading form…", then "No quick-create form is available for this activity". Call and Meeting work.

W2-B8Medium

Recurring tasks are never created

"Weekly, 3 times" is saved, but only the first task exists, even after completing it.

W2-B1Medium

Timeline misses deletes and attachments

Only created, field changed, restored and note entries appear. Record deleted and attachment added or removed are not logged.

W2-B3Low

A record can hold more than 10 tags

The tag API accepted an 11th tag. The limit is 10 (as in Zoho).

W2-B5Low

Pipeline shown as a raw id

Record page, list column and inline editor show the pipeline id; stages show keys like needs_analysis.

W2-B2Low

Timeline says "leads created"

The create entry uses the module key instead of "Lead created".

What passed

  • Create form checks (required fields, phone format), Save and New, inline edit with validation, change owner, delete with its warning, record not found page.
  • Custom views: create with criteria, rename, clone, pin, shared views, duplicate names and bad patterns refused.
  • Field filters with all operators; export to .xlsx / .xls / .csv keeps the filters (file had exactly the filtered rows).
  • Tags: create, rename, merge, delete, bulk tag (append and overwrite).
  • Notes (Arabic and emoji) and attachments: upload, preview, download, remove.
  • Lead conversion: targets listed, record created, lead marked converted, tags and history carried over.
  • Kanban drag between stages updates the stage and the totals.
  • Import: file checks, mapping, layout choice, result counts, error rows download, history and undo.
  • Global search for the owner: grouped results, deleted records left out. Activities from a record (call, meeting with guest), My Open Activities, My Work Queues.
  • Test user 1 can create and delete their own lead, but not the owner's (403).

Differences from Zoho (for the gap list)

  • No Clone on records; notes can't be edited or deleted.
  • Attachments refuse .txt and other types (Zoho takes any type).
  • "Coming soon": system-defined filters, Sheet and Print views, Drafts, Approve Leads, Deduplicate, Client Script, import manual approval.
  • Global search doesn't find notes or tags. The meeting popup has no Repeat. No "Save as view" from the filter panel.

Small notes, no ticket proposed: "Conversion failed. Please try again." doesn't name the field; owner change logs two timeline entries; "Sort: created_at" label; bin labels use module keys; import status "partially_completed" when nothing was created; Mass Update offers system fields; search matches any word and doesn't rank an exact name first.
