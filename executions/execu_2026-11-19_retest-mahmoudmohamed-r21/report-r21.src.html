NDC-3105

Failed actions, failed runs and the Failed only filter

PASS

Developer: workflow #146, client-engine #858 and #859 on staging. A failed action reads Failed, runs read Failed or Partly failed, and a new "Failed only" filter lists failed runs.

  • Two new rules on new tickets: one whose only action (Create Record) fails, one with Add Tags plus the same failing Create Record.
  • The all-fail run shows Failed; the mixed run shows Partly failed.
  • The failed action shows Failed, HTTP 422 and the full reason ("Calls needs Contact Name…"), not Cancelled.
  • Outcome filter "Failed only" lists both runs; the address keeps ?outcome=failed and Back to history returns to the filtered list.
