D-1 → NDC-3029 · Blueprint | Creating, editing, publishing or deleting a blueprint leaves no entry in the Audit Log

FAILMediumH12, M4
Steps
  1. Create a blueprint, edit it, publish it, delete it.
  2. Open Settings › Audit Log and filter on Blueprint.
Expected
One readable entry for each create, update, publish, restore and delete (Zoho logs blueprint changes).
Actual
Only "restored" and "purged" entries exist for blueprints. None of the creates, updates, publishes or deletes from 12–13 Nov are there.
Related
Earlier fix NDC-1643 (blueprint audit).

D-2 → NDC-3030 · Blueprint | Two people editing the same blueprint: the second save silently replaces the first person's change

FAILMediumH6
Steps
  1. Open the same blueprint in two tabs (or as two admins).
  2. Change something different in each and save both.
Expected
The second save is warned that the blueprint changed and can reload, as in Zoho.
Actual
Both saves succeed, and the first change is lost without any message.
Related
Same problem as NDC-2965 (Workflow Rules).

D-3 → NDC-3031 · Blueprint | A continuous blueprint does not run the next step by itself

FAILMediumJ15
Steps
  1. Make a blueprint with "Continuous" on, whose second transition has no During items.
  2. Run the first transition on a ticket.
Expected
The second transition runs on its own straight after (Zoho continuous blueprint).
Actual
The setting is saved, but the ticket stays in the middle state; the second step never runs (waited 30 s and more).

D-4 → NDC-3032 · Blueprint | Field changes made by a blueprint are missing from the ticket's History tab

FINDINGMediumF2, M1
Steps
  1. Make a transition with an After action "set field" (e.g. Description, or an address).
  2. Run it on a ticket and open the ticket's History tab.
Expected
A line "Description was updated, Old / New", marked as done by the blueprint.
Actual
History shows the status change and "ran QA F2 desc" but no field change. The server does keep it (ticket.field_changed, source blueprint). A manual change of the same field shows normally.
