Recheck on staging, 9 Nov 2026 (tenant NDC-Staging)

Every item was checked again on NDC-Staging (owner account, hierarchy mode Role, nothing switched). Numbers follow this ticket. Result: 0 built, 3 partly built, 16 still missing. The related bugs NDC-2412..2416 are all Done.

Partly built

  • 4. The texts now agree: higher-ranked profiles see lower-ranked profiles "in the same org unit and the units below it". This is an org-unit branch, not a role tree. Not re-run at runtime.
  • 15. Approvals now have an approver type "Levels" with a "Reporting depth" (how many levels up the reporting chain). Not visible: "all up to level N" and the fallback when the owner has no manager.
  • 16. CRM record visibility now offers Public, Public Read Only and Hierarchy. Still no separate Public Read/Write vs Read/Write/Delete.

Still missing

  • 1. Choice of who manages records of users with no manager.
  • 2. Warning listing where "Reporting To" is used when switching back to Role (same generic dialog both ways).
  • 3. Roles tree separate from profiles.
  • 5. Share Data with Peers.
  • 6. Transfer & Delete for a role / profile.
  • 7. Any user can still be chosen as manager (a User's list includes another User).
  • 8. Personal Settings still asks to paste a user ID.
  • 9. No Reporting Hierarchy section on the user, no Reports To column or filter.
  • 10. No prompt for the reports when a manager is deleted or suspended.
  • 11. No check when a manager's profile change breaks the chain.
  • 12. "Reporting To" not in reports, views, filters or merge fields.
  • 13. No workflow email to the record owner's manager.
  • 14. No "Reporting Manager" blueprint transition owner.
  • 17. No sharing rules (/iam/sharing-rules and /settings/data-sharing 404).
  • 18. No roles API (/iam/roles, /settings/roles 404).
  • 19. /iam/users/{id}/subordinates still 404.

Evidence (TAVI left, Zoho right): ev-01-preference-page-vs-zoho.png, ev-02-reporting-manager-vs-zoho.png, ev-03-roles-sharing-usage-vs-zoho.png.
