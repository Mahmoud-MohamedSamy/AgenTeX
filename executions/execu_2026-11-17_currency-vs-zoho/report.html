Add currency dialog compared with Zoho CRM

Scope. This comparison uses two screenshots only. Neither system was checked live. The Zoho screenshot shows the Edit dialog (Edit US Dollar - USD), and the TAVI screenshot shows the Add dialog, so behaviour 1 for Zoho is read from the Edit dialog title.

Annotated evidence

Behaviour by behaviour

1Choose the currencySAME
TAVICurrency picker (Euro), picked from a list.
ZohoCurrency shown in the dialog title (Edit US Dollar - USD); picked from Zoho's currency list when adding.
2Currency symbolGAP
TAVISymbol is a free-text box (€). There is no choice between code and symbol, and any text can be typed.
ZohoCode/Symbol is a dropdown: show the ISO code (USD) or the symbol ($).
3Exchange rateGAP
TAVIOne manual rate box only ("How many AED one EUR is worth"). No Automatic update option. Save stays disabled until a rate is typed.
ZohoUpdate Type: Automatic or Manual. The manual rate is typed in a box with the currency code in front of it (USD | 15.65).
4Active / inactiveSAME
TAVI"Active (can be chosen for records)" checkbox in the dialog; power button on each row of the list.
ZohoStatus toggle on each currency in the list, with an All Status filter.
5Number formatGAP
TAVINo Format section: no symbol position, no digit separators, no decimal places, no preview.
ZohoFormat section with Symbol Position (before or after the value), Digit Separators (1,234,567 and others), Decimal Places, and a live Preview (USD 1,234,567).
6Currencies listGAP
TAVIColumns: Currency, Symbol, Exchange rate (1 USD = 50 AED), Status, then edit, activate and delete icons. No Format, Update Type or Last Modified By columns, and no search.
ZohoColumns: Currency (link), Format (ILS 1,234,567), Update Type (Manual), Exchange Rate with an info icon, Last Modified By with date, and a Status toggle. A search box sits above the list.

What TAVI needs to match Zoho

  • A Code/Symbol choice instead of a free-text symbol box.
  • An Automatic option for exchange-rate updates, next to Manual.
  • A Format section: symbol position, digit separators, decimal places and a live preview.
  • Format, Update Type and Last Modified By columns in the currencies list, plus a search box.
