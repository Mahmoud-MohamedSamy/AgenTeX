# NDC-2971 Skills | Workflow Add/Remove skills list and Create Ticket Skills field offer deleted skills (plus inactive and other departments' skills); a ticket saved with a deleted skill keeps it
Summary
Skills that were deleted are still offered in two places: the workflow rule actions Add skills / Remove skills, and the Skills field on Create Ticket. A ticket can be saved with a deleted skill and keeps it.
The workflow list also offers inactive skills and every department's skills. Choosing a department for the rule does not narrow it. NDC-2933 covers inactive and other-department skills on the ticket Skills field; this ticket adds deleted skills and the workflow actions.
In Zoho Desk, a deleted skill disappears everywhere. A workflow rule's Add Skills list shows only the active skills of the rule's department.
Steps to reproduce
- Sign in to TAVI Desk (NDC-Staging) as an admin.
- Delete some skills (on 12 Nov morning, the 32 QA SK12 skills were deleted from Setup → Skills).
- Setup → Workflow Rules → open QA SK13 WF skills (Tickets, Departments = QA SK13 Dept A) → instant action Add skills. Scroll through the Skills list.
- Tickets → New Ticket and look at the Skills field.
- Create a ticket in QA SK13 Dept A with the deleted skill QA SK12 S1 and save. Reopen it.
Expected (Zoho Desk)
- Deleted skills are offered nowhere and are removed from tickets.
- A workflow rule's Add/Remove Skills list shows only the active skills of the rule's department. Zoho test, 12 Nov 2026: 13 options in Tech (QA SK13 S1–S12 + test). QA SK13 Inact (inactive) and the other department's skill were not listed.
Actual (TAVI)
- The Add skills list has 81 options: 32 deleted QA SK12 skills, inactive QA SK13 Inact (it can be ticked), QA SK13 HS of QA SK13 Dept B, and tier_1_support, billing, QA AS6 … of other departments.
- Create Ticket's Skills field offers the same 32 deleted skills.
- Ticket #3176 was saved with deleted QA SK12 S1 and still shows it under Ticket Information → Skills.
- At run time the rule skips the inactive skill (#3174 got 9 of 10), so the list promises skills that are never added.
Environment
- TAVI Desk, NDC-Staging (staging-desk.taviportal.com), owner account, 12 Nov 2026.
- Zoho Desk test portal (Enterprise trial), department Tech, 12 Nov 2026.
