# NDC-3056 Blueprint | Agents cannot see the blueprint's flow and transition conditions from a ticket
Summary
On a ticket inside a blueprint, Desk only shows the current state and the transition buttons available right now. Agents cannot open the whole blueprint to see which states come next, which transition leads where, and what each transition needs before its button appears. TAVI CRM already has this on its records: the "View configured actions" link in the Blueprint section opens a popup with this flow.
Steps to Reproduce
- In TAVI CRM, open a lead that is in a blueprint (for example AEX-01-BP, blueprint AEO-01).
- In the Blueprint section, click View configured actions. A popup shows each state, the transition between states and the condition, for example web → WebToReferral → referral, "Shown when: Company is not empty".
- In TAVI Desk, open a ticket that is in an active blueprint.
- Look for the same option on the ticket's blueprint card.
Expected Result
- The Desk ticket's blueprint card has a "View configured actions" option, the same as CRM.
- It opens the blueprint's flow: states, the transitions between them and each transition's "Shown when" condition.
- An agent can then see why a transition button is not showing yet and what has to be filled in first.
Actual Result
- The Desk ticket only shows the current state and the transitions available right now.
- If no transition is available, the agent has no way of finding out which condition is missing.
- The blueprint flow can only be seen in Settings → Blueprints, which agents normally cannot open.
Note
Compared with TAVI CRM, which runs on the same blueprint engine. Zoho Desk was not checked live. Not part of the Desk blueprint gap list NDC-2754.
Environment
staging-desk.taviportal.com (NDC-Staging) and staging-crm.taviportal.com, Microsoft Edge, Windows 10, 15 Nov 2026.
