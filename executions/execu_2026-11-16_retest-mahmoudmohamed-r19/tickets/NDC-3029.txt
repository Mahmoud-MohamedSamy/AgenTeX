# NDC-3029 Blueprint | Creating, editing, publishing or deleting a blueprint leaves no entry in the Audit Log
Summary
Blueprint changes are not recorded in the Audit Log at all. Zoho Desk logs every blueprint add, update and delete.
Steps to Reproduce
- Go to Settings › Automation › Blueprints and create a blueprint.
- Edit it (for example the description) and click Save and Publish.
- Delete the blueprint.
- Open Settings › Audit Log (All Entities, Any time).
Expected Result
- One readable entry for each change: blueprint created, updated, published and deleted, with name, user, IP and department.
Actual Result
- No entry for any of the four changes. On 13 Nov 20:24 Cairo blueprint "QA BP D1 audit" was created, edited, published and deleted; the log shows only sign-ins at that time.
- GET /audit/events?app_key=desk has no blueprint event either; the only blueprint entries ever seen are "restored" and "purged".
Zoho Desk
Setup › Audit Log lists blueprint "QA BP I4 throwaway" as Blueprint - (Tickets) · ADD, UPDATE and DELETE, each with user, IP and department.
Note
Spec rows H12 and M4. Related earlier fix: NDC-1643.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 12–13 Nov 2026. Compared live with Zoho Desk (test account techsolutionsegypt; test blueprint deleted afterwards).
