# NDC-3032 Blueprint | Field changes made by a blueprint are missing from the ticket's History tab
Summary
When a transition's After action changes a field, the ticket History tab does not show that change. The server records it.
Steps to Reproduce
- Create a blueprint whose transition has an After action "Field update" (e.g. Description = "QA F2D set by blueprint").
- Run the transition on a ticket.
- Open the ticket › History.
Expected Result
- A history line for the field change (old → new), marked as done by the blueprint transition.
Actual Result
- History shows "<agent> ran QA F2 desc in QA BP F2D" and the status change, but no Description line.
- GET /desk/tickets/{id}/history does contain ticket.field_changed for description (source blueprint).
- A manual change of the same field is shown normally. Same for an address field changed by the blueprint.
Zoho Desk
Ticket #191 History after a transition with an After field update: "Ticket updated as part of transition actions · Blueprint name … · Transition name QA move · Phone changed from -None- to 010000014".
Note
Found while running spec row F2 (address field, which passed) and M1.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 12–13 Nov 2026. Compared live with Zoho Desk (test account techsolutionsegypt; test blueprint deleted afterwards).
