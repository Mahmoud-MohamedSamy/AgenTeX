# NDC-3030 Blueprint | Two people editing the same blueprint: the second save silently replaces the first person's change
Summary
If a blueprint is changed in another tab or by another admin while you have it open, your Save and Publish overwrites that change with no warning.
Steps to Reproduce
- Open the same blueprint in two browser tabs (or as two admins).
- In tab 1 change the name and click Save and Publish.
- In tab 2 (still showing the old version) change only the description and click Save and Publish.
- Reload the blueprint.
Expected Result
- Tab 2 is told the blueprint changed since it was opened and can reload; no change is lost.
Actual Result
- Tab 2 saves and publishes with no message (Version 2).
- After reload the name is back to the old one: tab 1's rename is lost. Only tab 2's description is kept.
Note
Same problem as NDC-2965 (Workflow Rules). Spec row H6.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 12–13 Nov 2026.
