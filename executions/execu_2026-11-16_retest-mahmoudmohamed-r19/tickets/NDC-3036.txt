# NDC-3036 Blueprint | If the only owner of a transition is deactivated, nobody can run it and no warning is shown
Summary
A transition owned by one agent becomes impossible to run when that agent is suspended. Tickets waiting on it are stuck and the blueprint shows no warning.
Steps to Reproduce
- Create a blueprint where transition "QA onlyA" (Open → Escalated) has only agent A as owner.
- Put a ticket into it.
- Suspend agent A.
- As an admin open the ticket and the blueprint.
Expected Result
- Someone can still move the ticket (admin or a fallback), or the blueprint flags the transition as having no active owner.
Actual Result
- Ticket: "No transitions you can run"; Status locked. API run by the admin: 403 "You are not an owner of this transition."
- Designer: Status Active, no warning; re-saving the blueprint works with no message.
Note
Spec row D5. Agent A was reactivated right after the test. Not compared with Zoho.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 12–13 Nov 2026.

Fix (decision B-73): suspended, deleted or still-invited owners no longer count. When none of a transition's owners is active, any agent with access and edit rights on the ticket can run it.
