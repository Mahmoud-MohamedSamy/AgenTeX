# NDC-3035 Blueprint | Unsaved designer changes are lost when the session expires
Summary
If the session expires while a blueprint has unsaved changes, Save and Publish sends you to sign in and the changes are gone afterwards, with no warning.
Steps to Reproduce
- Open a blueprint in the designer and change the description (do not save).
- Let the session expire.
- Click Save and Publish, then sign in again.
Expected Result
- A warning before the change is lost, or the change kept (local draft) and restored after sign-in.
Actual Result
- "Your session expired. Please sign in again." (good).
- After sign-in the designer opens with the old description; the change is lost and nothing warned about it.
Note
Spec row H11. Not compared with Zoho.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 12–13 Nov 2026.
