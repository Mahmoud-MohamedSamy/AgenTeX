# NDC-2963 Workflow Rules | Script saved in an Add Comment action runs when an admin opens the rule
Summary
An Add Comment action body that contains HTML is rendered as HTML in the rule editor, so a script in it runs in the admin's browser.
Steps to Reproduce
- Save a rule (through the rules API) whose Add Comment body is <img src=x onerror="window.__xss=1">.
- As an admin, open the rule in the editor.
Expected Result
- The body is shown as plain text everywhere; no script runs.
Actual Result
- The editor renders the image tag and its onerror script runs (window.__xss is set).
- The rules list, Execution History and the ticket comment are safe.
Note
The input was saved through the API; the editor is the part that renders it unsafely.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 11–12 Nov 2026.
