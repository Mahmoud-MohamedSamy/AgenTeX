# NDC-2968 Workflow Rules | Create Record action skips required fields and leaves the new record without an owner
Summary
A Create Record action creates records that break the target module's required fields, and the new record has no owner. The run is logged as Succeeded.
Steps to Reproduce
- Create a rule On Create with a Create Record action in Calls, setting only the Start Time (Subject left out).
- Create a matching ticket.
- Open the new Call.
Expected Result
- The rule cannot be saved without the required fields, or the run fails with a clear reason.
- The new record has a real owner.
Actual Result
- The Call is created with no Subject; Call Owner is Unassigned and Created By shows "Unknown user".
- Execution History: CreateRecord Succeeded.
Note
The owner part is the Desk side of NDC-2726 (CRM: records created by Create Record don't take the triggering record's owner).
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 11–12 Nov 2026.
