# NDC-2967 Records API | 500 error when "kind" is not the first key of a field value
Summary
Creating a record through the API fails with a server error when the keys of a field value are in a different order.
Steps to Reproduce
- POST /api/v1/modules/{tickets}/records with a field value {"value":"x","kind":"string"}.
- Send the same request with {"kind":"string","value":"x"}.
Expected Result
- Both requests are accepted; JSON key order must not matter.
Actual Result
- First request: HTTP 500 INTERNAL_ERROR "An unexpected error occurred".
- Second request: HTTP 201, record created.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 11–12 Nov 2026.
