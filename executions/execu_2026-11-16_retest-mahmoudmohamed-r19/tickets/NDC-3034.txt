# NDC-3034 Ticket History | Blueprint lines show the internal name "BlueprintStateChanged" and text like "QA BP F2U|entered|Open"
Summary
Besides the readable blueprint lines, ticket History shows extra lines with an internal event name and internal detail text.
Steps to Reproduce
- Put a ticket into a blueprint and run a transition.
- Open the ticket › History.
Expected Result
- Only readable lines (e.g. "Entered blueprint … at Open", "<agent> ran <transition> in <blueprint>").
Actual Result
- Extra lines titled "BlueprintStateChanged" with Detail "QA BP JU: QA verify", "QA BP K: QA back" or the pipe-joined "QA BP F2U|entered|Open".
Zoho Desk
Every blueprint line is readable: "Blueprint applied · Blueprint name …", "Blueprint transition performed by <agent> · Blueprint name · Transition name · From state · To state", "Ticket updated on completion of transition".
Note
Spec row M1.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 12–13 Nov 2026. Compared live with Zoho Desk (test account techsolutionsegypt; test blueprint deleted afterwards).
