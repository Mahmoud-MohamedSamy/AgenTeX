# NDC-2834 SLA | An escalation email template that an SLA uses can be deleted with no warning
Summary
An escalation email template chosen in an SLA escalation level can be deleted from Email Templates with only a generic confirmation. Nothing says an SLA uses it. Afterwards the SLA silently falls back to the default escalation email, and the admin only finds out by opening that SLA target ("A template that no longer exists"). Desk already refuses to delete business hours that an SLA uses, so templates behave differently.
Steps to Reproduce
- Create an escalation email template (Agent Notification, SLA escalation) in Setup › Email Templates.
- In Setup › SLA & Escalation, create an SLA whose response escalation level 1 uses that template, and save.
- Go back to Setup › Email Templates, open the template's actions menu and click Delete.
- Read the confirmation and click Delete.
- Open the SLA again, go to its target and look at the escalation's Agent Notification Template.
Expected Result
- When deleting, the admin is told the template is used by an SLA (name it), and either cannot delete it or is asked to pick a replacement.
Actual Result
- The dialog only says "will be deleted. This can't be undone from this page."; the template is deleted.
- The SLA now shows "A template that no longer exists" and "The default escalation email is being used". This is visible only inside the target editor.
Note
Zoho's help covers only the delete steps (public templates cannot be deleted); what Zoho does for a template an SLA uses is not documented and was not seen live. Low priority because escalations still go out with the default email.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, 1440×900, owner account, 10 Nov 2026. Compared with Zoho Desk help articles (live Zoho Desk did not load on this network).
