# NDC-2966 Workflow Rules | "Send happiness email" is logged as Succeeded while ratings are off
Summary
With Customer Happiness switched off, the Send happiness email action sends nothing but is logged as Succeeded with no reason.
Steps to Reproduce
- Make sure Customer Happiness is off.
- Create a rule On Create with the action Send happiness email.
- Create a matching ticket and open Execution History.
Expected Result
- The run says the action was skipped because ratings are off (the editor itself says "Nothing is sent while ratings … are switched off").
Actual Result
- Execution: SendHappinessEmail Succeeded, with no reason (ticket #3163). Nothing in the ticket history.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 11–12 Nov 2026.

Annotated evidence attached (WF-I30-happiness-email-succeeded-while-off.png).
