# NDC-2962 Workflow Rules | A line break in a webhook header value adds an extra header to the outgoing request
Summary
A Webhook action header value that contains a line break is sent as two headers. Anyone who can edit rules can add any header to outgoing webhook requests (header injection).
Steps to Reproduce
- Create a rule On Create with a Webhook action to a request catcher (webhook.site).
- Add header X-QA with the value a + line break + Injected: 1 (saved through the rules API).
- Create a matching ticket and look at the request the catcher received.
Expected Result
- Header names and values with line breaks are refused at save.
- Reserved headers such as Host are refused too.
- Only the configured headers are sent.
Actual Result
- The rule is saved.
- The catcher received two headers: x-qa: a and injected: 1. Execution History: Webhook Succeeded.
- A Host header override is also accepted.
Note
Zoho Desk workflow rules have no Webhook action, so this is not a Zoho comparison; it is a security defect in TAVI's own feature.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 11–12 Nov 2026.
