# NDC-3063 Blueprint | The state time limit only accepts hours, with no option to switch between minutes, hours and days
Summary
When you set a time limit on a blueprint state, the "Time limit in hours" and "Warn before, in hours" boxes only take hours. There is no unit picker, so minutes or days have to be converted into hours by hand.
Steps to reproduce
- Settings → Automation → Blueprints → open "test blueprint" (Tech, version 16).
- Click the On Hold state to open its panel.
- Look at the Time limit section.
Expected result
Each box has a number plus a unit picker (Minutes / Hours / Days), as in Zoho Desk. A 30-minute or 3-day limit can then be entered directly.
Actual result
- Both boxes are labelled "in hours" and have no unit picker.
- To get 30 minutes you type 0.5, and for 3 days you type 72.
- A limit that isn't a round number of hours comes back as a rounded decimal, so 20 minutes shows as 0.33.
Additional notes
- The time is saved in minutes, so the system can already store minutes. Only the input is limited to hours.
- "Warn before" has the same problem.
- Annotated evidence attached: boxes 1–2 mark the two hours-only boxes; box 3 marks the Clock setting, which is not part of this bug.
Environment
staging-desk.taviportal.com (NDC-Staging), Edge, 16 Nov 2026.
