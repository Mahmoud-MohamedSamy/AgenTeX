# NDC-3057 Workflow Rules | The rule's condition summary shows the stored value "pending_approval" instead of the option label "Pending approval"
Summary
On a Desk workflow rule, the folded condition line shows the option's stored value in quotes (Approval Status = "pending_approval") instead of the label agents see everywhere else ("Pending approval"). Opening the condition for editing shows the right label, and saving does not change the folded text.
Steps to Reproduce
- Go to Desk → Settings → Automation → Workflow Rules.
- Open a rule whose condition uses a list field, for example "Test Workflow Based on Ticket Approval Status" with Approval Status is Pending approval.
- Look at the folded condition line under Condition 1.
- Click the condition to open it, then click Done and Save.
Expected Result
- The folded condition reads Approval Status = Pending approval, the same label shown in the editor and on tickets.
Actual Result
- The folded condition reads Approval Status = "pending_approval": the stored value, in quotes, as if it were typed text.
- Opening the condition shows Pending approval correctly.
- After Done and Save (saved successfully), the folded line still shows "pending_approval".
Note
- Only Approval Status is shown in the recording. Other list fields (Status, Priority, custom list fields) were not checked.
- Zoho Desk not checked live.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge 156, Windows 10, 15 Nov 2026.
