 Fixed and live on tavi (metadata-engine #239, deployed 17 Nov 2026 at 15:14 UTC). Moving to Ready For Test. 

 As the QA lead decided, B-14 no longer holds for an agent who can only read the ticket. A transition owner can run the transition only if they can edit the ticket, or if the ticket is shared with them at Full access. They are not offered it, and a run through the API is refused, when the ticket belongs to another agent and they can only open it, or when it is shared with them read-only or restricted.

 One exception stays: an owner from another department named in the blueprint's Transition Owners. The blueprint shares the ticket with that department at the access level the admin picks, so that its agents can run the step, and they still can.

 Checked on staging in NDC-Staging through the API, logged in as a normal Customer Support agent (a probe account standing in for CES2), with a temporary blueprint whose transition only that agent owns:

 
 On a Customer Support ticket the account owner owns, the agent can open the ticket but is not offered the transition. A run answers 403 "You are not an owner of this transition." The ticket stays Open, and the agent can still open it afterwards. Before this deploy, the same setup offered the transition.

 On a ticket the agent owns, the transition is offered and the run moves the ticket to On Hold.

 
 "This ticket is not available" after the run: the agent could open the ticket only because they own a transition from its current state. That access ends when the ticket leaves the state. An agent who can only read can no longer run, so they keep seeing the ticket. #4181 and #4182 behave the same way: their blueprints no longer give CES2 an open transition, so CES2 cannot open the account owner's tickets.

 To know when you retest:

 
 If a transition's only owner cannot edit a particular ticket, nobody can run it on that ticket until its owners change: on the ticket's Assign owners when the blueprint has dynamic owners, otherwise by editing the blueprint.

 The refusal says "You are not an owner of this transition", even though the agent is named as one. Better wording is a follow-up.

 
 The probe blueprint and tickets are deleted. Not checked: the ticket screen in the browser for this case (the API answers above are the list and run the screen uses).
