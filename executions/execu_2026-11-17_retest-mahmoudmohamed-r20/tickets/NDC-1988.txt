# NDC-1988 Layout rules, validation rules, nested picklists
Smarter ticket forms. Example: if Type = Refund, "Order number" becomes mandatory.
Phase 3. Needs first: nothing.
Details
- Layout rules: show fields / sections and make fields mandatory when a field meets conditions.
- Validation rules with conditions across fields and their own alert message (50 per department).
- Different picklist values per layout.
- Help Center access per field (editable / read-only / hidden for customers).
- Nested picklists (up to 6 levels).
- Field encryption for sensitive custom fields, with the ePHI label.
