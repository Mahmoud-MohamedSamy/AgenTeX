# NDC-3058 Workflow Rules | Add Tags action says "Search or create a tag" but a new tag cannot be created from it
Summary
In a workflow rule's Add Tags action, the Tags box placeholder reads "Search or create a tag…". Typing a name that does not exist only shows "No matching tags". There is no option to create the tag, so only existing tags can be used.
Steps to Reproduce
- Go to Desk → Settings → Automation → Workflow Rules and open a rule (or create one).
- Add an Add Tags action, or open an existing one, with Configure inline selected.
- Click the Tags box and type a name that does not exist yet, for example test.
Expected Result
- The list offers Create "test". Choosing it creates the tag and adds it to the action, as the placeholder says.
Actual Result
- The list shows only "No matching tags", with no create option.
- The page sends no request to create the tag.
- The only way to use a new tag is to create it first in Tags settings, then come back to the rule.
Note
- Pressing Enter after typing was not tried in the recording.
- Zoho Desk not checked live.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge 156, Windows 10, 15 Nov 2026.

Decided 17 Nov 2026: a Desk workflow rule does not create tags. Moving to Ready For Test for the wording fix.
Desk tags belong to a department and are created on Tickets → Tags. A rule can run across several departments, so a tag it created would have no department to belong to. Rules pick from existing tags, and the tag box now says "Search tags…" so it no longer suggests otherwise. This differs from Zoho on purpose.
To retest: in a Desk rule's Add Tags or Remove Tags action, the box says "Search tags…", and typing a name that does not exist shows "No matching tags".
