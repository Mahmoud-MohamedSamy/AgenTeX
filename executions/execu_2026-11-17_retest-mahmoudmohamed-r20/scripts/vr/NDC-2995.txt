# NDC-2995 Layout Rules | "Show related lists" picker lists the same relation many times [Bug]
Summary
In the rule editor, the picker of the "Show related lists" action shows the same module relation many times and has no Notes entry.
Environment
- NDC-Staging (staging-crm.taviportal.com), Chromium, 12 November 2026, admin account.
- Leads, rule editor.
Steps to reproduce
- Open Settings > Modules and Fields > Leads > Layout Rules and edit a rule.
- Add the action "Show related lists" and open its picker.
Expected result
Each related list appears once with a clear name. Zoho lists each related list once, including Notes.
Actual result
- Entries such as "Leads (Lookup 2)" and "Leads (Multi-Select Lookup)" appear up to 7 times.
- There is no Notes entry.
- Also, the Leads record page shows no related-list sections, so the effect of the action cannot be seen.
Notes
- Found in Layout Rules case F21.
- Evidence: crm-F21-pick.png (attached).
