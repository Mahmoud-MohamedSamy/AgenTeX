Email - Advanced Configuration
ADVANCED CONFIGURATION
Advanced functionalities that can help you customize the email channel to your business needs and improve your overall ticketing experience. These are organization-level settings, but some can be disabled for individual departments.
Learn More
Auto Cc e-mail replies to your support mailbox
Automatically send a carbon copy (Cc) of all email messages that you send, to your support mailbox.
Configure
Create Contacts using the "Reply To" email address
By default Contacts are created using the “From” address of incoming emails. When this option is enabled, the “Reply To” address in incoming emails will be used to create Contacts.
Configure
Show Agent name in Ticket replies and outgoing emails
The Agent's name (both first and last names) along with the support email address, will be displayed in Ticket replies and outgoing emails. When disabled, the friendly name of the support email address will be displayed.
Configure
Original Sender Detection
When an Agent forwards an email to the help desk, it will create a Ticket with the email's original sender-identified using the #original_sender keyword or from the email header-as the Contact. If this option is disabled, the forwarding Agent will be set as the Ticket's Contact.
Configure
Note:
When forwarding, agents can insert the "#original_sender" keyword followed by the customer’s email address at the top of the email body to help with identification.
Keyword
#original_sender
Example: #original_sender {<email>}
Automatically set Ticket threads as private, if requestor is not the recipient.
While replying to Tickets, threads are automatically set as private if requestor is not the recipient. Agents can, however, set the thread as public if required.
Configure
Forwarded threads are always private regardless of this setting.
Add threads using Ticket ID
When enabled, an independent email containing a Ticket ID in its subject will be threaded to the corresponding Ticket in the help desk, provided it's sent by one of the following users.
