Summary
For View-only departments, the agent's department settings say the agent "cannot reply, edit, close or move" tickets. In practice an agent with View only access to Tech and Customer Support can still edit fields, add attachments and save the Resolution on those departments' tickets, including a Closed ticket. Every change is accepted and saved under the agent's name.
Steps to Reproduce
As an admin, go to Desk → Settings → Agents, open an agent (Mahmoud Mohamed in the recording) and set Tech and Customer Support to View only.
Sign in as that agent.
Open ticket #3981 (Tech). Change Phone, add an attachment and edit the Resolution.
Open ticket #74 (Customer Support, Closed). Change Due Date and edit the Resolution.
Expected Result
As the settings text says: the agent can see the tickets and add private comments, but cannot reply, edit, close or move them.
Edit, attachment, resolution, Reply and Close controls are hidden or disabled.
If a change is sent anyway, the server refuses it.
Actual Result
#3981 (Tech): Phone saved ("Record updated successfully"), attachment images.png added, Resolution updated ("Resolution saved").
#74 (Customer Support, Closed): Due Date set to 17/11/2026 and Resolution added, both saved.
Reply All, Close ticket and Status are available on the View-only ticket.
The server itself reports the agent's access to both departments as View only.
Note
The agent's Desk profile is Desk Administrator. Not yet checked with an agent on the Desk Agent profile.
Zoho Desk not checked live.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge 156, Windows 10, 15 Nov 2026.
