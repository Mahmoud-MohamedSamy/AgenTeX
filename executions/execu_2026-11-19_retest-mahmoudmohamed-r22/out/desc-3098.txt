Summary
Which tickets an agent sees can only be set for the whole tenant (Setup › Ticket Access: Private, Public Read Only, Public) plus roles. There is no per-agent choice, so one agent cannot be limited to their own (and unassigned) tickets while the rest of the department sees every ticket. Found in the Desk go-live ticket access run (departments, teams, sharing, moving), NDC-Staging, 17 Nov 2026.
Steps
- Open Setup › Agents › an agent: look for a ticket-access choice for that agent.
- Open Setup › Ticket Access: the data-sharing level applies to all agents.
- Try to limit one Customer Support agent to own + unassigned tickets while the other Customer Support agents keep seeing all Customer Support tickets.
Expected
As in Zoho: each agent has a ticket access type — all tickets of their departments, own + unassigned, or own + team + unassigned — independent of the other agents.
Actual
No per-agent setting. The only levers are the tenant-wide data-sharing level and the role hierarchy, which affect every agent of that role or the whole tenant.
