# NDC-2965 Workflow Rules | Saving a rule silently overwrites a change made by someone else
Summary
If a rule is changed in another tab or by another admin while you have it open, your save overwrites that change with no warning.
Steps to Reproduce
- Admin A opens a rule in the editor.
- Meanwhile the rule is renamed in a second tab (or by another admin).
- Admin A changes the description and clicks Save.
Expected Result
- Admin A is told the rule was changed and asked to reload; no change is lost.
Actual Result
- The save succeeds with no warning, and the rename from the other tab is lost (the name goes back to the old one).
- The save request carries no version, so the server cannot detect the conflict.
Note
Same problem was filed for Scoring Rules (NDC-2939) and Global Sets (NDC-2868).
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 11–12 Nov 2026.
