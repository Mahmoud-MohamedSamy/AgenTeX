# NDC-2951 Workflow Rules | A rule can have only one Field Update action
Summary
A rule cannot hold a second Field Update action (with the same delay). Zoho Desk allows several field updates in one rule.
Steps to Reproduce
- Create a workflow rule for Tickets.
- Add a Field Update action, then add a second instant Field Update action.
- Save.
Expected Result
- Several actions of the same type are allowed, as in Zoho Desk: up to 10 field updates, 10 alerts and 10 tasks per rule.
- One Field Update can also set several fields.
Actual Result
- Error 400: "A rule can have only one 'FieldUpdate' action with the same delay."
- Two Task actions are now accepted, so only Field Update (and other one-per-type actions) are limited.
Zoho Desk
Help "Creating Workflow Rule": up to 10 alerts, 10 tasks and 10 field updates per rule. In the live editor the Field Update dialog has a "+" to set more fields.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 11–12 Nov 2026. Compared live with Zoho Desk (test account, nothing left behind) and Zoho Desk help articles.
