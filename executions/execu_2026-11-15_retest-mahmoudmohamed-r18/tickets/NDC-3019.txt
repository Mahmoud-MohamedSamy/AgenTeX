# NDC-3019 Validation Rules | CRM rule list shows the raw layout id instead of the layout name
Summary
On a fresh page load the CRM Validation Rules list shows the layout's id in the Layout column. The name appears only after a save in the same page.
Environment
- Staging, tenant NDC-Staging, 12–13 Nov 2026
- Owner account; Leads › Validation Rules, English and Arabic
- Test data used the prefix "QA VR1112" and was deleted after the check.
Steps to reproduce
- Create a rule for a custom layout.
- Reload Settings › Modules and Fields › Leads › Validation Rules.
Expected result
The Layout column shows the layout name, as the Desk list does.
Actual result
- Layout column: "9f0069ec-a4a0-4f50-8342-44c1af1be1f5" instead of "QA VR1112 Layout".
- Seen in English and Arabic, and again on 13 Nov with a new layout.
Notes
- Case B2.
- Evidence: crm-B2-list.png (attached).
