# NDC-3017 Validation Rules | A message set to show "at the top of the form" is not brought into view
Summary
With "Show the error: At the top of the form", a refused save draws the message at the top, but the page does not scroll to it and the field is not marked. A user lower down the form sees nothing happen.
Environment
- Staging, tenant NDC-Staging, 12–13 Nov 2026
- Owner account; Leads, QA layout
- Test data used the prefix "QA VR1112" and was deleted after the check.
Steps to reproduce
- Create a rule with "Show the error: At the top of the form".
- Open a new lead, scroll down to the checked field, type a value the rule refuses.
- Click Save without scrolling.
Expected result
The page scrolls to the message (or the field is also marked), so the user sees why the save failed. Zoho shows the alert where the user can see it.
Actual result
- The message is added at the top of the form, out of view.
- The page stays where it is and the field has no error mark.
Notes
- Case E2.
