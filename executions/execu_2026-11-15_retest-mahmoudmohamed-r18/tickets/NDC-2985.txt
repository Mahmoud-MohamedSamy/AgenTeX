# NDC-2985 Layout Rules | A field hidden by field permission leaks its value in the record timeline
Summary
A field hidden by field permission leaks its value in the record timeline. The record API and field panel hide it, but Recent activity shows "QA LR1112 date was updated from blank value to 2026-05-01".
Environment
- NDC-Staging (staging-crm.taviportal.com), Chromium, 12 November 2026, admin account.
- Leads layout "QA LR1112 Layout" with test fields type (Refund, Question, Partner, Other), tier, filter (pick lists), order, note, reason (text), vip (checkbox), radio, date and email2. Test data was deleted after the run.
Steps to reproduce
- Hide the date field for profile User.
- Sign in as a CRM User and open a record where the owner set date.
Expected result
The hidden field's value is not shown anywhere to that profile.
Actual result
- The record API and field panel hide it, but Recent activity shows "QA LR1112 date was updated from blank value to 2026-05-01".
- This is a field-permission bug, found while testing layout rules.
Notes
- Test cases K9 in the Layout Rules test sheet (https://claude.ai/artifact/PUdj9axtAjCR8UQpegu5qC).
- Evidence: crm-K9-timeline.png (attached).
