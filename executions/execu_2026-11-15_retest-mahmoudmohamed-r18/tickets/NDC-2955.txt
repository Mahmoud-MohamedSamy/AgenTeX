# NDC-2955 Workflow Rules | Rule name length is only checked when you save
Summary
The rule name box accepts any length; the limit appears only as an error when you save. Zoho Desk's name box stops at its limit while you type.
Steps to Reproduce
- Click New Rule (Tickets) and type a rule name longer than 200 characters.
- Add a condition and an action.
- Click Save & Activate.
Expected Result
- The name box stops at the limit while typing (Zoho: 50 characters), so no error at save.
- If the description keeps its 2000-character limit, the box shows it while typing.
Actual Result
- No limit while typing.
- At save: "Name: The length of 'Name' must be 200 characters or fewer. You entered 253 characters."
- The description is also refused above 2000 characters only at save.
Zoho Desk
Rule Name box has maxlength 50 and stops typing at 50 characters; Description has no limit.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 11–12 Nov 2026. Compared live with Zoho Desk (test account, nothing left behind) and Zoho Desk help articles.
