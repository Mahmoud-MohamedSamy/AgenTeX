# NDC-2953 Workflow Rules | The rules API accepts a Field Update on the system field Created By
Summary
The rule editor correctly does not offer Created By in a Field Update, but the rules API accepts it and saves the rule. Other system fields such as Ticket Number are refused.
Steps to Reproduce
- Send POST /api/v1/workflow/rules with a Field Update action on created_by.
- Send the same with ticket_number.
- In the rule editor, add a Field Update and search the field list for "Created".
Expected Result
- created_by is refused like ticket_number ("Field is read-only and cannot be changed").
- As in Zoho Desk, only editable ticket fields can be set by a Field Update.
Actual Result
- created_by: HTTP 201, the rule is saved.
- ticket_number: HTTP 422 "Field 'ticket_number' is read-only and cannot be changed." (correct).
- Editor: "Created" gives "No results found" (correct).
Zoho Desk
The live Field Update field list offers only the 14 editable ticket fields (Contact Name … Language); Created By and other system fields are not offered.
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 11–12 Nov 2026. Compared live with Zoho Desk (test account, nothing left behind) and Zoho Desk help articles.
