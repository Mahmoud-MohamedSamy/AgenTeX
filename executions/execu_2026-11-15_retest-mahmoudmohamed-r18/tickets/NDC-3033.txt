# NDC-3033 Ticket History | An address field change is shown as raw code text
Summary
When an address field changes, the History tab shows the old and new value as JSON text.
Steps to Reproduce
- Add an address field to Tickets (it was a QA field, deleted after the test).
- On a ticket with a full address, change the City from Cairo to Tanta.
- Open the ticket › History.
Expected Result
- A readable line, e.g. "City: Cairo → Tanta", or the full address as plain text.
Actual Result
- Old {"zip": "11511", "city": "Cairo", "state": "Cairo Gov", "street": "1 QA Street", "country": "Egypt"}
- New {"street":"1 QA Street","city":"Tanta","state":"Cairo Gov","zip":"11511","country":"Egypt"}
Note
Not compared with Zoho (Zoho Desk tickets were not checked for an address field type).
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 12–13 Nov 2026.
