# NDC-2981 Layout Rules | The rule editor cannot build text, number, date, regex or length rows
Summary
The rule editor cannot build text, number, date, regex or length rows. The row field list offers only choice and user fields.
Environment
- NDC-Staging (staging-crm.taviportal.com and staging-desk.taviportal.com), Chromium, 12 November 2026, admin account.
- Leads layout "QA LR1112 Layout" with test fields type (Refund, Question, Partner, Other), tier, filter (pick lists), order, note, reason (text), vip (checkbox), radio, date and email2; the same setup on Desk Tickets. Test data was deleted after the run.
Steps to reproduce
- Open the rule editor, add a condition row and open its field list.
Expected result
Zoho lets condition rows use any field type.
Actual result
- The row field list offers only choice and user fields.
- Rows built through the API work on the form, but the editor shows them as "qa_lr_text (unknown field)".
Notes
- Test cases D9, D10, D11, D12 in the Layout Rules test sheet (https://claude.ai/artifact/PUdj9axtAjCR8UQpegu5qC).
- CRM and Desk share the same rule engine, so this applies to both apps.
- Evidence: crm-C20-fields.png (attached).
