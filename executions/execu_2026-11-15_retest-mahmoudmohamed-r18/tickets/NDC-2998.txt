# NDC-2998 Workflow Rules | The rules API accepts a date trigger on a field that is not a date
Summary
A rule with the trigger "A Date-Time field" can be saved through the API on a text or pick-list field (Subject, Priority). The rule editor only offers date fields; a field that does not exist is refused.
Steps to Reproduce
- Send POST /api/v1/workflow/rules with trigger { kind: DateFieldRelative, dateFieldName: "subject", offsetSeconds: -3600 }.
- Repeat with dateFieldName "priority", then "due_date", then "nope_field".
Expected Result
- subject and priority are refused because they are not date or date-time fields.
- due_date is accepted; nope_field is refused.
Actual Result
- subject: HTTP 201, rule saved with dateFieldName subject.
- priority: HTTP 201, rule saved.
- due_date: 201 (correct); nope_field: 400 "Unknown field(s) for module Tickets" (correct).
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 11–12 Nov 2026.
