# NDC-2977 Layout Rules | Blueprint transition ignores the layout rule's mandatory field
Summary
Blueprint transition ignores the layout rule's mandatory field. The transition form asks only for message, attachment and note.
Environment
- NDC-Staging (staging-crm.taviportal.com), Chromium, 12 November 2026, admin account.
- Leads layout "QA LR1112 Layout" with test fields type (Refund, Question, Partner, Other), tier, filter (pick lists), order, note, reason (text), vip (checkbox), radio, date and email2. Test data was deleted after the run.
Steps to reproduce
- Blueprint on the QA layout moves type Question to Refund.
- Rule: Refund makes order mandatory.
- Run the transition with order empty.
Expected result
Zoho shows the layout rule's mandatory fields inside the transition form.
Actual result
- The transition form asks only for message, attachment and note.
- The record moves to Refund with order empty.
Notes
- Test cases G10 in the Layout Rules test sheet (https://claude.ai/artifact/PUdj9axtAjCR8UQpegu5qC).
- Evidence: crm-G10-dialog.png (attached).
