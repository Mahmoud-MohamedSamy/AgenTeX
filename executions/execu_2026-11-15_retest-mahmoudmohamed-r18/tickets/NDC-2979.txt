# NDC-2979 Layout Rules | A rule on a user field (Lead Owner) never fires
Summary
A rule on a user field (Lead Owner) never fires. The rule saves and reads back correctly, but order never shows on the form.
Environment
- NDC-Staging (staging-crm.taviportal.com and staging-desk.taviportal.com), Chromium, 12 November 2026, admin account.
- Leads layout "QA LR1112 Layout" with test fields type (Refund, Question, Partner, Other), tier, filter (pick lists), order, note, reason (text), vip (checkbox), radio, date and email2; the same setup on Desk Tickets. Test data was deleted after the run.
Steps to reproduce
- Rule: Lead Owner is ndc-staging-owner, then show order.
- Open the create form with that owner, then pick another user and pick the owner back.
Expected result
Zoho applies rules on user lookup fields.
Actual result
- The rule saves and reads back correctly, but order never shows on the form.
Notes
- Test cases D5 in the Layout Rules test sheet (https://claude.ai/artifact/PUdj9axtAjCR8UQpegu5qC).
- CRM and Desk share the same rule engine, so this applies to both apps.
- Evidence: crm-D5.png (attached).
