# NDC-2964 Workflow Rules | Double-clicking Save & Activate creates two identical rules
Summary
The Save & Activate button stays active while the save runs, so a double click creates two identical active rules.
Steps to Reproduce
- Click New Rule (Tickets), add a condition and a Field Update.
- Double-click Save & Activate.
- Search the rules list for the rule name.
Expected Result
- One rule is created; the button is disabled while saving.
Actual Result
- Two identical active rules "QA AO WF EV10 double save" were created at the same minute (seen 3 times on 12 Nov).
Environment
staging-desk.taviportal.com (NDC-Staging), Microsoft Edge, Windows 10, owner account, 11–12 Nov 2026.
