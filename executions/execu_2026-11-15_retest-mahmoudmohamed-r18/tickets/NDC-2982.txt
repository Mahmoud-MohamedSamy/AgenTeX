# NDC-2982 Layout Rules | Removing one target field from the layout switches off the whole rule
Summary
Removing one target field from the layout switches off the whole rule. The whole rule stops: note is no longer mandatory.
Environment
- NDC-Staging (staging-crm.taviportal.com and staging-desk.taviportal.com), Chromium, 12 November 2026, admin account.
- Leads layout "QA LR1112 Layout" with test fields type (Refund, Question, Partner, Other), tier, filter (pick lists), order, note, reason (text), vip (checkbox), radio, date and email2; the same setup on Desk Tickets. Test data was deleted after the run.
Steps to reproduce
- Remove "date" (a target of the vip rule) from the layout.
- Tick vip.
Expected result
Only the missing target is flagged. The rest of the rule keeps working.
Actual result
- The whole rule stops: note is no longer mandatory.
- Other rules that mention date in one row stop too.
- The same happens when a section is deleted (J6) or an option is deleted (J8).
Notes
- Test cases J3 in the Layout Rules test sheet (https://claude.ai/artifact/PUdj9axtAjCR8UQpegu5qC).
- CRM and Desk share the same rule engine, so this applies to both apps.
- Evidence: crm-J3.png, crm-J3-editor.png, crm-J6.png, crm-J8.png (attached).
