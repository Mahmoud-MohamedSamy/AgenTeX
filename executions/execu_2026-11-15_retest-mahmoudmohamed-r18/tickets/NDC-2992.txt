# NDC-2992 Layout Rules | Screen readers are not told a rule-mandatory field is required
Summary
Screen readers are not told a rule-mandatory field is required. Only a visual asterisk is shown.
Environment
- NDC-Staging (staging-crm.taviportal.com), Chromium, 12 November 2026, admin account.
- Leads layout "QA LR1112 Layout" with test fields type (Refund, Question, Partner, Other), tier, filter (pick lists), order, note, reason (text), vip (checkbox), radio, date and email2. Test data was deleted after the run.
Steps to reproduce
- Pick Refund so order becomes mandatory.
- Inspect the order input.
Expected result
The input carries aria-required or required.
Actual result
- Only a visual asterisk is shown.
- The input has no aria-required.
Notes
- Test cases M5 in the Layout Rules test sheet (https://claude.ai/artifact/PUdj9axtAjCR8UQpegu5qC).
