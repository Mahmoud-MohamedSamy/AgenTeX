# NDC-2984 Layout Rules | Deleting a layout leaves its rules behind, still active
Summary
Deleting a layout leaves its rules behind, still active. The rule stays "active" in the list and API with definitionError "Layout ... is not a layout of this module."
Environment
- NDC-Staging (staging-crm.taviportal.com and staging-desk.taviportal.com), Chromium, 12 November 2026, admin account.
- Leads layout "QA LR1112 Layout" with test fields type (Refund, Question, Partner, Other), tier, filter (pick lists), order, note, reason (text), vip (checkbox), radio, date and email2; the same setup on Desk Tickets. Test data was deleted after the run.
Steps to reproduce
- Delete a layout that has a rule.
Expected result
Zoho removes a layout's rules with the layout.
Actual result
- The rule stays "active" in the list and API with definitionError "Layout ... is not a layout of this module."
Notes
- Test cases J7 in the Layout Rules test sheet (https://claude.ai/artifact/PUdj9axtAjCR8UQpegu5qC).
- CRM and Desk share the same rule engine, so this applies to both apps.
