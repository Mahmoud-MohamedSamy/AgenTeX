# NDC-3004 Web Forms | A disabled web form shows a blank page instead of a "not available" message
Summary
A disabled web form shows a blank page. Found in the Desk go-live retest, Wave 4 (W4-39), NDC-Staging, 12 Nov 2026. Where: Web form hosted/iframe page after Disable on Setup › Web Forms.
Steps
- Disable a web form on the Web Forms screen.
- Open its embed (iframe) address.
Expected
A short message such as "This form is not available".
Actual
The page is completely blank; its session call returns 404.
Zoho Desk
Not checked live: the Zoho test account has no web forms. A blank page with no message is a defect on its own.
