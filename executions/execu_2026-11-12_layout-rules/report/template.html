What layout rules are

A layout rule changes a record form while the user fills it. When a chosen field (the primary field) gets a certain value, the form reacts: it shows extra fields or sections, makes fields mandatory, and in CRM it can also filter options, lock fields, set or suggest values, or show messages. Example: "when Type is Refund, show Order number and make it mandatory".

  • CRM has 13 actions. Desk has 3: show fields, show sections and make fields mandatory. Desk rules can also be limited to departments and to the Help Center.
  • Rules should run wherever a record is created or changed: the form, inline edit, the stage bar, Blueprint, mass update and web forms.
