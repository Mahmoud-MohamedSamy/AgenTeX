What passed

  • Users list, search and the user dialog (profile, org unit, reporting manager, read-only referral code, overrides).
  • Invite one user, Invited status, resend and cancel; bulk invite with a result per row; bad email and missing profile refused.
  • Suspend: sign-in refused and the open session cut. Reactivate: sign-in works again.
  • Permission overrides (grant and deny) with history that names who did it. A CRM Admin can't grant a permission they don't hold.
  • Profiles: clone copies all 29 permissions, add, rename, delete. A profile in use can't be deleted; a rank above your own is refused.
  • Denied permissions really block: users, workflow rules, actions, approvals, reviews and audit view-all.
  • Permissions matrix: "1 pending change", Discard keeps the old value, Save stores it, Owner-only rows are marked.
  • Field permissions set from the Field Permissions tab are stored; hidden fields stay out of list results.
  • Org units: create, rename, move; cycles refused; a unit with children or users can't be deleted; creation is audited.
  • Security policy values out of range are refused. Login history: columns, CSV export, revoke one session, clear all sessions of a user.
  • Audit log filters; "view own" users see only their own events and sessions.
  • Personal pages, account info edit, same-password change refused. Setup hides links and admin pages refuse a direct URL without permission.
  • Hierarchy suite: 27 regression tests.

Differences from Zoho (for the gap list)

  • The Users screen has no Active / Inactive views.
  • Security Policies has only the session policy; Zoho also has password, lockout and MFA policies.
  • The permissions matrix has an Inherit column; Zoho profiles are flat.
