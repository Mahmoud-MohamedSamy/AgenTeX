# NDC-2807 Bulk Operations | Bulk operations (mass update, mass delete, empty Recycle Bin) stop when you leave the page
Summary
Bulk operations (mass update, mass delete and emptying the Recycle Bin) should keep running in the background until they finish, wherever the user goes in the app. Right now they only run while the user stays on the page where they started. If the user navigates away, the operation quietly stops partway, leaving part of the records updated or deleted and the rest untouched. The user then has to start it again. The steps below use Empty Recycle Bin, which is how it was recorded; the same applies to mass update and mass delete.
Steps to Reproduce
- Go to Settings → Data Administration → Recycle Bin (the bin has 942 items).
- Click Empty Bin, type DELETE and confirm.
- A banner appears: "Deleting… 200 of 942 items done. You can keep using the page."
- While it's still deleting, click Tickets in the top menu, then open Settings → Recycle Bin again.
- Look at the Recycle Bin page.
- Repeat with a mass update or mass delete on a large list of records, leaving the page while it's in progress.
Expected Result
- Any bulk operation (mass update, mass delete, empty Recycle Bin) keeps running after the user leaves its page or moves to a different page.
- Coming back to the page shows the operation's progress, or the finished result once it's done.
- A bulk operation can't be started a second time on the same records while one is still running.
Actual Result
- The progress banner is gone and the deletion has stopped.
- The bin still shows 842 items, and Empty Bin can be clicked again as if nothing were running.
- Starting it again begins from the remaining count, and parts of it fail without any message.
- Mass update and mass delete are exposed to the same interruption when the user leaves the page mid-run.
