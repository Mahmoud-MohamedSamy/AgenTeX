# NDC-2869 Global Sets | Two labels in the set editor are not translated in Arabic
Summary
With the interface in Arabic, the Global Sets editor is right-to-left and almost fully translated, but two labels stay in English.
Environment
- Staging, staging-crm.taviportal.com, tenant NDC-Staging, 11 Nov 2026
- Owner account, language العربية
Steps to reproduce
- Switch the language to العربية from the language menu.
- Open Modules and Fields › Global Sets and edit a set that has unused values.
Expected result
Every label in the editor is in Arabic.
Actual result
- "VALUES (2)" above the value list is in English.
- "Move 0 to used values" under Unused values is in English.
Notes
- The language was switched back to English after the check.
- Evidence: B5-arabic-editor-untranslated.png
