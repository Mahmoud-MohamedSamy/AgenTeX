# NDC-2806 CRM Global Sets
Summary
Bring CRM Global Sets to parity with Zoho CRM by building on top of the shared core metadata engine already established in Zoho Desk. This replaces the original one-line description and covers all requirements from the "Global Sets: our build vs Zoho" analysis.
Scope
- Target & Scope: Global Sets (reusable picklist option pools) can be referenced across custom and standard CRM modules. Editing a Global Set updates option values, colors, and display labels across all linked module fields simultaneously.
- Creation & Conversion Workflows: Support three creation paths:
- Creating a global set from scratch.
- Converting an existing set of local picklist values to a global set via field properties.
- Cloning an existing global set (X_Cloned).
- Value Management & Unused Pool:
- Support adding, renaming, and replacing options. Replacing an option automatically propagates the change across existing records and dependent components (workflows, criteria, reports).
- Removed items move to an Unused Values section (managed via the gear icon) rather than hard-deleting immediately.
- Field Association & Value Mapping:
- Support linking new or existing picklists.
- When associating an existing picklist with un-matched local values, provide an Associate Picklist with Global Set popup for manual or automatic mapping, highlighting dependent rules via a View associated places link.
- System Safeguards & Limits:
- Block deletion or value replacement if a global set is associated with more than 15 fields.
- Enforce batch limits (e.g., moving max 50 values from unused to used per request when past the threshold).
- Prevent association on locked system fields (e.g., Lead Status, Deal Stage, Case Status).
- Usage & Dependency Tracker: A dedicated "Used In" metadata view showing every module, layout, rule, and report using the global set.
- Step Wizard / Management Interface:
- Access path: Setup > Customization > Modules and Fields > Global Sets.
- Management views for master list, values reordering, color code toggles, and cloning.
- Permissions: crm:global_set:view and crm:global_set:manage seeded in IAM, along with a CRM Settings menu entry.
- Audit Log & Recycle Bin: Comprehensive audit logging matching Zoho’s exact action entries (e.g., tracking additions, renames, replacements, and option deletions) alongside ticket NDC-1858.
