W3-12
Where
Setup › Custom Actions › API sources › Edit (Authentication)

Steps

  1. Create an action by pasting an OpenAPI spec that has no securitySchemes (many simple specs don't).
  2. Edit its API source: Authentication = API key, header X-QA-GL-W3-Key, a key; Save ('Credentials saved').
  3. Run the action from a ticket and look at the request the receiver got. Repeat with Bearer and Basic.

Expected

The key is sent, as the form says: 'Sent with every request the actions of this source make.'

Actual

No auth header on 4 runs (API key, Bearer, Basic; from the screen and the API). The same API key on a second source whose spec declares an apiKey scheme is sent (header x-qa-gl-w3-key). receiver headers: content-length, content-type, traceparent, accept-encoding, host  (no X-QA-GL-W3-Key)
secured spec source, same credential → receiver headers include x-qa-gl-w3-key
