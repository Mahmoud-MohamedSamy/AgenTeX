How each wave runs

  1. Snapshot of everything the wave can touch, and the Plane state of every ticket in it.
  2. Automation first: the wave's existing suite, API and screens (crmaccess + crmhierarchy, crmrecords, crmautomationorder, crmchannels, crmsetup, crmdeskintegration).
  3. By hand for every function the suite doesn't cover, every changed screen, and every newly added feature; each new check is added to the automation.
  4. Zoho check (read-only) for every retested ticket and every failure.
  5. Verify each candidate bug once more from scratch; separate test defects from app bugs.
  6. Evidence: one annotated image per retested ticket and per failed case, in the approved layout.
  7. Clean up and diff against the snapshot; report with decisions; Gate 2.
