Wave 1 · Who can see and do what

What we tested: users and invites, profiles and permissions, departments (org units), the reporting hierarchy, data sharing, security settings, login history, the audit log, personal settings and field permissions. We signed in as different kinds of users (owner, admins, a supervisor, normal users) to check what each one can and can't reach, on screen and through the API.

Result: 71 of 77 checks pass.

Working now (16 old tickets fixed)

Field permissions are respected everywhere (screen, API and import) · the audit log records changes · built-in profiles can't be renamed · a user can't change their own manager · sessions show the right status · teamspaces are private to their members · the button label "Create profile" is fixed. Tickets: NDC-2381, 2293, 2418, 1172, 1699, 1701, 1337, 1593, 1599, 2416, 2543, 2546, 2547, 2415, 613, 2414.

Still not working (already ticketed)

NDC-2412Still fails

A supervisor can't see the leads of a lower-ranked person in the same department, so managers miss their team's records.

NDC-2657Still fails

A user without access sees the raw text "Missing required permission …" on the Permissions page. Confusing, not harmful.

NDC-2658Still fails

Inviting a user when no seat is free shows a raw code instead of a message.

New problems found

R2W1-B2High

A manager can see another department's leads. A Manager in HR, without "view all", can open leads that belong to a user in Sales. Managers should only see their own team. If real, staff can see customers of other departments. Seen in two separate runs. It may be the same visibility logic as NDC-2412, wrong in the other direction.

R2W1-B1Medium

The new "AI Agent" profile can be renamed. This build protected the built-in "User" profile, but not the new one. Anything that finds the profile by its name could break. (We renamed it back at once.)

Zoho has it, TAVI doesn't (scope, not bugs)

Data sharing rules (TAVI only has "public" or "by hierarchy" per module) · password, lock-out and two-factor (MFA) policy screens.

Not tested in this phase

Switching the hierarchy mode, session and security policy edits, business hours, the Referral Code sync — these change things for everyone, so they run in Phase 4. Invites and deleting a user are blocked because no user seat is free. NDC-1343 skipped (In Progress).

Wave 2 · Everyday work with records

What we tested: creating, editing, deleting and restoring records in all 15 modules; the record page, notes, timeline, tags, lead conversion; list, custom views, kanban, split view, filters, search, import and the recycle bin. New this time: merge, mass update of every field type, moving records to another owner, record locking, and Cases and Sales / Purchase Orders in full.

Result: 59 of 67 checks pass (after rerunning the deal tests, which our own workaround had broken).

Working now

All 15 modules work end to end · Cases and Sales / Purchase Orders work with every field type · mass update and moving owners work · filters return the right records · import and the recycle bin work · deals can be created with their pipeline again (NDC-2382) · the Pipelines settings page loads (NDC-2386) · no module turns itself on as a conversion target (NDC-2388) · a deleted view in a link opens "All Leads" (NDC-2098, now fixed). Also still passing: NDC-1484, 1832, 1302, 1603, 1597, 1600, 1601, 1593, 1599, 2302, 1197, 2282.

Still not working

NDC-2136Worse

The Leads list is very slow: 22, 35 and over 40 seconds to show rows (target 1.5 s; it was 12–25 s on 25 Oct). This is the problem users will notice most.

NDC-1823Marked Done, still fails

When converting a lead, fields Zoho locks (Probability, Expected Revenue, durations) can still be edited. The conversion form also took about 25 seconds to open.

NDC-1193Still fails

A completely empty Customer can be saved.

NDC-2122Still fails

An invalid filter pattern ("1 AND 2") is accepted.

NDC-2280Still fails

A long view name runs over the other columns.

NDC-2137Close

Kanban shows its first cards in 2.7 seconds (target 2 s).

New problems found

R2W2-C1Medium

Record locking doesn't lock. You can save a rule to lock records, but locked records can still be edited, and the rule accepts any text as its condition. Anyone relying on it (for example to freeze closed deals) gets no protection. Its settings tab still says "In Development".

R2W2-C2Low

Raw column names on Home. The "My Tasks" and "My Meetings Today" cards show headers like "due_date" instead of "Due Date".

Probably fixed, waiting for the developers

These tickets are still In Progress, so they aren't marked as passed, but on this build they look fixed: moving a deal to another pipeline (NDC-2621, 1312, 1316, 1324) · deletes shown on the timeline (2624) · "Lead created" wording (2627) · the 10-tag limit (2625) · recurring tasks (2623) · search for normal users (2622) · pipeline name shown (2626).

Zoho has it, TAVI doesn't

Merge only through the API, no screen · no Clone · number filters have no "greater or equal", "less or equal" or "between".

Not tested in this phase

Attachments, mass delete and the work queue were not rerun (mass delete by condition and Empty Bin affect everyone). I can add them to Phase 3.
