Goal

Make Desk Skills work like Zoho Desk. An admin defines skills with a type, criteria and agents, and Desk adds the matching skills to each ticket. Skill-based round robin then sends the ticket to an agent who holds them. This ticket lists only the skills setup that is still missing. Routing rules are in NDC-2275 (RR-9, RR-18).

Already in TAVI Desk (checked 1 Nov 2026)

  • Setup → Assignment Rules → Skills tab with Preferences: "Add skills to tickets by their criteria" (off by default), and where added skills go (top, bottom, or the order of the list).
  • Skill types: add, rename and delete. Deleting a type keeps its skills and leaves them untyped.
  • Each skill has a type, a description and criteria (AND / OR). A skill removed from the field shows "Removed from the field", with Clear.
  • Skills are the options of the Tickets "Skills" field, added and renamed in Modules & Fields.
  • Agent Skills tab: tick the skills each agent holds.
  • Skill-based round robin: only agents who hold every skill on the ticket are eligible, and offline agents are skipped.
  • Workflow actions: Add skills, Remove skills (1–25), Recalculate skills, Reassign ticket based on skills.

Missing compared with Zoho Desk

  1. Skills per department. Zoho sets skills, the skill preference and the skill order per department (up to 30 active skills per department), and maps agents to skills per department. TAVI has one list and one set of preferences for the whole company.
  2. Active / Inactive status. In Zoho, an inactive skill is not added to tickets and is not used for assignment. TAVI has no status; the only way to stop a skill is to delete the field option.
  3. Add Skill on the Skills page, with a required type. Zoho's Add Skill asks for Skill Name and Skill Type (both required), Description, Criteria and Agents, and a type can be added inline. TAVI has no Add Skill button: the name comes from Modules & Fields and the type is optional.
  4. Agents on the skill form. Zoho: "Associate agents with this skill…". TAVI: agents can only be picked one agent at a time on the Agent Skills tab.
  5. Search and filters. Zoho has separate Skills and Skill Types tabs, with filters for Name, Skill Type, Agents and Status. TAVI shows a plain list with no search or filters.
  6. Reorder skills. Zoho reorders skills per department, and its "order in settings" placement follows that order. TAVI offers the "list order" option but has no way to reorder.
  7. Recalculate and assign one ticket. Zoho can run Recalculate Skills and skill-based assignment on a single ticket. TAVI has these only as workflow actions.
  8. Show where a skill is used. Zoho lists the rules that use a skill. TAVI gives no warning about the workflows or rules that still use a deleted skill.
  9. Limits. Zoho allows at most 10 skills on a ticket, with the first having the highest priority. TAVI has no limit on the field, and the workflow action allows 25.

Questions

  • The Department form still has its own Routing setting (Round robin / Least busy / Skill match). Which one decides when it conflicts with the assignment rules?
  • Should skills be added to tickets before Direct Assignment, as step 1 of the execution order in NDC-2275 (EO-1)?
