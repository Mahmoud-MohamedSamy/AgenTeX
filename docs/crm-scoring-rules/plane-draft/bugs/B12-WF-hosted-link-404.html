Summary

The hosted link of a web form does not open, for Desk and CRM forms alike. Visitors get a plain "404 Not Found (nginx)" page. The same form works through its iframe address, so the form itself is fine; only the hosted link address is not served.

Environment

  • Staging, staging-crm.taviportal.com, tenant NDC-Staging, 12 Nov 2026 (build index-C_wkzBy1)
  • CRM: owner account; Leads web form "QA SR1112 Lead form" (Full Name, Lead Source), "Allow hosted link / iframe" on; opened signed out in Edge
  • Desk: enabled form "Tech Webform" on NDC-Staging; Desk forms use the same address (staging-crm.taviportal.com/embed/feedback/…)

Steps to reproduce

  1. Settings › Web Forms › New advanced form. Module Leads, layout Standard. Add Lead Source.
  2. In Settings, tick "Allow hosted link / iframe" and click Create form.
  3. On Publish & how to use, the Hosted link card shows "On" with an address like https://staging-crm.taviportal.com/embed/feedback/f/<key> and a QR code.
  4. Open that address in a signed-out browser (or click Test your form).
  5. For comparison, open the address from the Plain iframe card (…/embed/feedback/index.html?key=<key>&mode=frame).
  6. Repeat steps 3–5 with an enabled Desk form (Desk › Settings › Web Forms, e.g. "Tech Webform").

Expected result

The hosted link opens the form on its own page, so it can be shared by link or QR code, as the Publish page promises ("The form on its own page, and a QR code to it").

Actual result

  • The hosted link answers 404 Not Found from nginx, every time.
  • Same for the Desk form "Tech Webform": hosted link 404, its iframe address loads (200).
  • The iframe address of the CRM form loads, sends ("Thank you. Your request has been submitted.") and creates the lead.

Notes

  • First reported in NDC-1488 comments (26 Oct, 29 Oct: /embed/feedback/ needs the same fallback to /embed/feedback/index.html that NDC-2634 gave the portal links). NDC-1488 is now Done but the 404 is still there; NDC-2732 and NDC-2751 point to NDC-1488 for it.
  • The test form, lead and scoring rule were deleted after the check.
