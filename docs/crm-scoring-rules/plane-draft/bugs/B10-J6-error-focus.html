Summary

When Create fails validation in the scoring rule editor, the fields with errors are marked, but keyboard focus stays on the Create button. Keyboard and screen-reader users are not taken to the first problem.

Environment

  • Staging, staging-crm.taviportal.com, tenant NDC-Staging, 12 Nov 2026
  • Owner account

Steps to reproduce

  1. Scoring Rules › New Scoring Rule.
  2. Leave the name and the field rule empty and press Create.

Expected result

Focus moves to the first field with an error (Rule name).

Actual result

  • "Required." messages appear and 4 controls get aria-invalid, but focus stays on Create.
