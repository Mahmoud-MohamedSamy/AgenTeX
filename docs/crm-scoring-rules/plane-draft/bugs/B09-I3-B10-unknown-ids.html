Summary

Deleting a scoring rule id that does not exist answers 204, and listing rules for a module id that does not exist answers 200 with an empty list. The page for an unknown module shows "No scoring rules for yet" with a blank module name and an active New Scoring Rule button.

Environment

  • Staging, staging-crm.taviportal.com, tenant NDC-Staging, 12 Nov 2026
  • Owner account

Steps to reproduce

  1. DELETE /scoring-rules/00000000-0000-0000-0000-000000000002 (or delete the same rule twice).
  2. GET /scoring-rules?module_id=00000000-0000-0000-0000-000000000009.
  3. Open /settings/automation/scoring-rules?module=00000000-0000-0000-0000-000000000009.

Expected result

404 SCORING_RULE_NOT_FOUND and 404 MODULE_NOT_FOUND (both codes exist and GET/PUT already use the first), and the page shows "This module no longer exists."

Actual result

  • DELETE answers 204 (twice in a row for the same rule as well).
  • The list answers 200 [].
  • The page shows "Choose a module" and "No scoring rules for yet"; New Scoring Rule stays enabled.
