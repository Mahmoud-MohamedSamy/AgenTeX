Layouts | A department layout's mandatory fields are not enforced — the ticket is saved with them empty

Summary

A field marked mandatory on a department's ticket layout is not checked when the ticket is saved, so a ticket in that department is created with its mandatory fields empty. Rules that require a field (layout rules, validation rules) are checked; only the layout's own mandatory flag is ignored. NDC marks 4 to 18 fields mandatory on each department form, for example Manual Invoice 9, ADM 18 and NDC Finance TKT 15.

Steps to reproduce

  1. In Setup → Layouts and Fields → Tickets, open the layout QA NDC Manual Invoice (assigned to department QA NDC Manual Invoice).
  2. Check that these fields are marked mandatory on the layout: Agent id, Need to issue invoice, Transaction Type, Number of Transaction, Number of transaction validation (plus Subject, Contact, Status, Department).
  3. Create a ticket in department QA NDC Manual Invoice with only Subject, Contact, Status = Open and Department filled, using that layout.
  4. Save.

Expected

  • The save is refused and lists each empty mandatory field, for example "Agent id is required", as Zoho Desk does for the department's layout.
  • No ticket is created.

Actual

  • The ticket is saved with all five mandatory custom fields empty.
  • The mandatory flags are still shown on the layout when it is read back, so the setting is stored but not applied.
