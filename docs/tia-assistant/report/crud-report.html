Tia: can it create, update and delete?

Records, modules, fields, layouts, automation and pipelines in CRM and Desk, asked in plain words as the Owner.

In short

  • Records: Tia created and updated a CRM lead through cards, but could not delete it. In Desk it refused to create a ticket, telling the Owner they have no access.
  • Modules and layouts: not supported. Tia refuses to create modules or layouts and says modules cannot be deleted.
  • Fields: Tia created a Leads field, but could not rename it (internal error) or delete it (asked for a record ID).
  • Automation and pipelines: only the CRM workflow rule could be created. Its rename and delete were "prepared" with no card. Assignment, approval and review processes, blueprints, scoring/validation/layout rules, pipelines, web forms, buttons, SLAs, macros and tags could not be created.
  • Safety held: nothing happened without a confirm. Every card for a real item was rejected and nothing real changed.

How it was run

  • One chat per object type. For each type: "Create … named QA TIA CRUD …", then "Rename it to … v2", then "Delete …". Each request ends with "Prepare it as a card for me to confirm."; if no card came and Tia did not refuse, one follow-up was sent: "Yes, please prepare the card now."
  • Cards for QA items were confirmed. If the create failed, Tia was asked to rename and delete an existing item instead, and any card was rejected (capability check only).
  • Automation was asked to stay inactive and limited to records named "QA TIA CRUD".
  • An earlier attempt at 09:23 stopped after 3 requests because the workspace Tia daily limit was reached (see NDC-3309); the run was restarted from the start after the limit was raised.
