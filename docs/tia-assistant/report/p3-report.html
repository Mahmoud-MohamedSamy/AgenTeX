In short

  • Safety of cards holds up well: double confirm, confirm after cancel, stale or deleted records, Tia switched off, suspended user and expired cards (15 minutes) are all handled correctly. Locks, validation rules and field permissions are enforced on Confirm.
  • But Tia can change the wrong field: asked to set a lead's "Title", it changed the lead's Name — and the card said "name", which a user would easily confirm.
  • Desk: Tia can no longer change or create tickets for anyone, including the Owner, so the Desk rule checks were blocked.
  • Knowledge: an uploaded file works (after Deploy) but answers cite no source; Desk help-center articles cannot be used.
  • Injection: planted instructions were ignored, but text dressed up as a Tia card was presented to the agent as a real pending proposal.
  • Mobile: Tia is not in the Android app.
