Correction — NDC-3319 is a false positive. The "blank replies" in the first create/update/delete run were my test script's fault: when Tia sends its answer in one piece (no streamed chunks), the text arrives only in the final message, which the script did not read. Re-reading every chat from history, none of the 72 answers was blank — they were recipe refusals, "I couldn't build this", internal errors and "Sorry, I couldn't answer that just now". The earlier report has been corrected. NDC-3319 should be cancelled (waiting for your go before changing Plane).

  • Users without "Chat with Tia" are blocked in every app: Tia status, chat, capabilities and chats all return 403 ("Missing required permission 'ai:tia:use'").
  • A Desk Administrator can chat in Desk, CRM and Omnichannel but cannot open the setup API, read or change the AI policy, or deploy (403).
  • Nobody but the owner of a chat can read it; other people's action cards cannot be confirmed (404 for those who can chat, 403 for those who cannot).
  • Unchanged from the first run (see the earlier reports): audience ("Who can use Tia"), switch, apps, suspended users, field permissions, tenant isolation.
