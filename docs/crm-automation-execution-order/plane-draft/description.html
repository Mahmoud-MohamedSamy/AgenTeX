Summary

We compared CRM's automation processes and their execution order (Assignment Rules → Review Process → Workflow Rules + Actions → Approval Process → Blueprint) with Zoho CRM on Leads, Deals and Tasks. This ticket lists what Zoho has and CRM does not have yet. The execution-order holder is NDC-1255. Each item has an annotated image (CRM left, Zoho right) attached to this ticket.

Already done in CRM

  • All five processes exist and can be set up on Leads, Deals and Tasks.

  • Assignment rules run only for Web Form, API and Import, with ordered entries (first match wins), availability check, follow-up task and fallback, like Zoho.

  • Review process has rules with an "Others" fallback, field-level review, rejection reasons, notifications, SLA escalation and resubmit.

  • Workflow rules have Create, Edit, Create or Edit, Delete, Field Changed and Date-Time triggers, Recurring / One time, instant and scheduled actions.

  • Approval process has levels with Users, Role, Groups, Levels, Manager, Record Owner and User Lookup Field approvers, final and rejection actions, record modification, process admins, delegate, takeover and resubmit.

  • Blueprint has Before / During / After, common, automatic and parallel transitions, SLA, mass include/exclude and versions.

  • CRM also has review on Tasks, review delegation, a review channel picker and review retention of 30–365 days, which Zoho does not have.

Missing — execution order and entry points

  1. Import can start only workflow rules ("Trigger workflow rules"). Zoho's "Trigger automation and process management" also runs review, approval, blueprint and CommandCenter on imported records. Image 01.
  2. Manual approval of imported records. Today the import wizard shows "Coming soon". Image 01.

Missing — workflow rules

  1. Record Score and Record Notes triggers. Today only Record Action and Date-Time are offered. Image 02.
  2. Add Meeting, Schedule a Call, Function and Create Connected Record actions. A "Custom Function" action type exists in the code but is never offered. Image 03.
  3. Assign Owner by an assignment rule, plus "only online users", "email the new owner" and "transfer related records". Today only Users, Org Units, Profiles and User Fields. Image 04.

Missing — review process

  1. Functions on review events (submission, review, rejection, resubmission). The API object has a webhookUrl field with no screen. Image 05.

Missing — approval process

  1. "Anyone" or "Everyone" for Role and Group approvers, and sequential or parallel for Everyone. Image 06.
  2. Call Functions after approval or rejection really running. Today it can be added but "runs as a no-op in this version". Image 07.

Missing — blueprint

  1. Convert (Leads), Custom Actions (functions) and Tags after a transition. "Create record" is also not in the After list of the blueprint checked. Image 08.

Could not be checked

  • The real run-time order (review holds workflow, approval and blueprint; blueprint waits for approval), lead conversion and the Timeline order need a functional run. They are covered by the test spec, which runs next; results will be reported separately.

  • Possible bug to check separately: staging-crm sessions end every 10–15 minutes even in a single tab.
