TAVI CRM missing features

One list of everything Zoho CRM has, or the team plan asks for, that TAVI CRM does not have yet. It merges the go-live feature inventory with every Plane ticket that lists CRM gaps, and shows which gaps still have no ticket.

staging-crm.taviportal.com (NDC-Staging) compared with Zoho CRM Enterprise (org943261092). Plane project NDC, read on 26 Oct 2026. Nothing was changed in Plane. Bugs in features that already exist are not in this list.

Summary

Findings

  1. 3 missing features block Wonder Travel's go-live: more than one currency, order totals on Sales and Purchase Orders, and validation rules on picklists. All three are in NDC-2536 and all three still failed on 26 Oct. See Wonder Travel go-live blockers.
  2. 16 missing features have no Plane ticket. Case escalation, parent account hierarchy, manual record sharing, PDF and mail-merge templates, a label translation editor, user import, territories, GDPR and consent, schedules, cadences, macros, a webhook watch API, the 3CX provider, calendar sync, marketplace extensions and holidays.
  3. 3 more are only partly covered. Groups, the assignment threshold, and Social / SalesSignals / SalesInbox. A ticket mentions each one, but no ticket asks for the feature itself.
  4. 5 rows of the 25 Oct inventory are out of date. Export, undo import, Mass Update and web forms are built. Recurring tasks exist but are broken (NDC-2623), so that is a bug, not a gap. Two Work Queue items from NDC-1819 are also built.
  5. Work Queue (NDC-1819) still misses 4 things: Zoho's filter panel, Pin / Hide in the column menu, pin in Manage Columns, and the Add Note icon on a row. Most of the ticket is done.
  6. NDC-1869 (custom views, 20 items) is closed as Done, but the items were not re-checked on screen. The 26 Oct retest still found "Save filter" and the system filters missing, so the rest need a quick check before they count as done.
  7. Some tickets give developers nothing to work from. NDC-2496 (Email Feature) and NDC-2534 (Import from Zoho CRM) have no description. NDC-2031 and NDC-2032 still wait for the agreed list of modules and settings pages.
  8. Most gap tickets are still in Backlog. Of the 46 tickets checked, only the Work Plan, Home Page and Teamspace items are In Progress.

      How to read it

      • Missing: no screen and no API. Coming soon: the menu item exists but only says "Coming soon". Partly: some of it exists; the row says what is missing.
      • Inv. is the row id in the go-live inventory (R records, C customization, U users and security, A automation, M communication, S sales and analytics, I integrations, G general). "—" means the gap was found only in Plane.
      • Plane shows the tickets that already ask for the feature, with their state on 26 Oct 2026.

      Sources and method

      • Go-live feature inventory, 25 Oct 2026: 121 features, 24 missing and 7 coming soon, plus the gaps inside partly built rows.
      • Plane: all 271 items in the CRM module, in every state, read through the Plane API; the whole NDC project (1,190 items) searched for CRM, Zoho, missing, gap and coming soon.
      • Local gap lists in the QA repository: automation execution order, CRM ⇄ Desk integration, hierarchy preference and custom views.
