# Builder research (agent, condensed)

Model: Portal (Manage Portal; users Active/Inactive/Pending; portal admin; super admin; My Portals) -> Departments (Enterprise; name, users, role per user; user in many depts; Default dept) -> Survey -> Pages (title<=100, desc<=5000, unlimited) -> Questions (IDs letters A,B..) -> Choices. Survey children: custom variables, theme, settings, quotas, timers, collectors, tags.
My Surveys filters: All, Published, Drafts, Closed, Shared by Me, Trashed; tags; search. Close Survey / Close Collector, Reopen; closed page message. Survey End Date. Closed also when plan response limit hit. No archived/expired/scheduled-open documented.
Ops: edit name/category/tags; duplicate (name+tags); delete -> trash -> restore; permanent delete "Yes, Delete This Survey"; no folders (tags); Transfer Survey (to user/department, recipient accepts, leaves your account); Send Copy, Export PDF, Print. Builder question trash (Question / Custom Variable tabs, restore, empty).
Create: scratch, template (250+/300+, 10 categories), duplicate, import (Free 10 q, paid 50), Quick Editor (paste), AI. Question Bank: Template Gallery, Existing Surveys, Bulk Question Builder.
Question ops: Edit, Clone, Move (page + before/after), Move to Trash. Page: add (title/desc), edit info, clone, move, delete; drag reorder. Type change only within family & before publish.

Common q settings: rich text question (images w/ hover text + click zoom/redirect, links, video), Insert Variable (piping), mandatory + error msg, required number of choices/rows/fields (at least/at most/exactly/between), choice entry (paste lines / individual boxes / predefined choices), Other (label), Not applicable (excluded from mean), ordering (randomize/flip/rotate/ascending; keep last N fixed), Comments field, Prepopulate (initial value or CRM/Recruit/URL param/HubSpot; editable flag), hint, Carry forward choices (from question; All/Displayed/Not displayed/Answered/Not answered), Display Logic + Answer Display Logic tabs, ePHI -> Encrypt answer, exclusive choices.
Types: MC one/many; Dropdown one/many; Boolean (on/off labels, toggle/checkbox, default No); Image selection (<=1050KB, label, 16:9/4:3); Image star rating; Rating scale Likert (0-10 range, end labels, numbers/smileys/custom images custom set or range set, flip) and Weighted Choice (label + weight, show weightage); Star rating (3-10 stars, N/A); NPS (0-10 fixed, promoters 9-10/passives 7-8/detractors 0-6, numbers/smileys/boxes/circles/rectangle/images <=50KB, color schemes, end labels); Slider (number/%, start, end, initial, step, left/mid/right labels); Ranking (N/A); Continuous Sum (labels, textbox/slider, validate sum =,<,>,between, min/max/decimal, hide total); Matrix choice one (force ranking one per column) / many (required rows/cols, exclusive); Matrix rating scale (Likert/weighted); Matrix star; Matrix dropdown (choices per column); Matrix textbox (format all/per column: short answer/number/email/date formats MM/DD/YYYY, MMM DD YYYY, DD/MM/YYYY, DD MMM YYYY + range); Matrix grid (per column incl dropdown, copy from column); Short answer (max 255, size 40, validate predefined regex/contains/length/custom regex, encrypt); Long answer (lines x chars, <=5000); Number (min/max/decimals); Email; Full name (first/last labels); Multiple textboxes (per-field formats); Contact info (sub-field labels); Date/Time (format, range, include time); File upload (multiple fields; doc/image/sheet/media/custom ext; size less than/between; count exactly/between; 10MB/file); Signature (ask name, redo); Heading/Description (rich text).
No CSAT/CES/heatmap/address types (CSAT only a report metric). CAPTCHA is a setting.

Logic: Display logic always/never/display only if/hide only if, AND/OR, condition pattern ((C1 and C2) or C3), copy conditions; hidden mandatory not required. Answer display logic per choice (also comments/N/A), auto-hide question if too few choices. Page skip logic (on page; go to next page / end page / disqualification page; specific page unconfirmed). Disqualification. Operators text: equal, not equal, contains, doesn't contain, starts, ends, answered, not answered; number: =, !=, <, >, between, answered, not answered. Sources: variables (URL params, CRM, Recruit, HubSpot, Deluge), questions, scores, custom script (JS/Deluge; application.survey.question.A.response, application.survey.urlparam["x"]; returns true; test with sample data; blocks window/document/eval), others (collector). Piping: missing value -> question hidden. Custom variables: URL Parameter, Label, Type Text/Email/Number/Choice(/Date), encrypt. Question randomization: none / all (randomize/flip/rotate) / selected; excluded when logic/piping on same page.
Scoring (Plus+): correct answer scoring (quiz, grades: N grades with range + label) or weighted scoring; negative allowed; ranges for number/date/slider; not scorable: ranking, email, contact, name, file, heading. End page variables: score %, value, total, page score.

Look & feel: Preferences toggles: progress bar, question numbers, CAPTCHA, previous button, skip first page if prepopulated; button labels Submit/Next/Previous/Continue Pop-up; message language (RTL Arabic/Hebrew/Urdu/Persian/Yiddish). Themes: My Themes + customizable; tabs General (color scheme, font, opacity, corners, shadow, border, size standard/large), Background (image 3000x1500 or pattern+color), Header (alignment, bg, logo, title), Body (colors, fonts, answer field colors, textbox, buttons), Footer; no custom CSS. Header: logo JPEG/PNG 250x85; title survey name or text. Intro page (title, desc, Begin Survey label). T&C (description, condition label; Next disabled or error). End page: Zoho thank you / summary of responses / show submitted response / custom message / redirect URL with dynamic params; End Page Logic; other system pages Disqualification, Response Editing Restriction, IP Restriction, Closed Survey, Over Quota. Languages: default + additional (135: 91 full, 44 partial); manual / Google Translate / spreadsheet; reports filter by language. Accessibility: Settings > Preferences > Compliance > Advanced Accessibility.
Response prefs: link per response, download links for signature/files, merged document; access org/SAML org/public/password.
Timer: survey (min/max, redirect, time extension requests queue Pending/Approved/Rejected/Expired) and page; disables Previous.
Quotas: survey (1), collector (1 per collector), conditional (many, question+operator+choices, balanced %); full -> close survey / end session to over-quota page / continue as over quota (count as complete); precedence.

Collaboration: Share Survey (Advanced Options): co-owners Read/Write or Read Only; collaborators can't send copy/transfer/custom theme/email distribution. Dept roles (Enterprise): Department Admin, User, Contractor (own surveys only), Report Viewer; custom roles Allow/Deny/Read Only over Department (others' surveys, tags, themes, images), Survey (builder, basic ops, launch ops, response actions, export, share, transfer), Report (basic reports, individual responses, export/schedule/print, share, delete responses). Review: invite reviewers by email (no account, valid <=7 days, comments), preview link generate/turn off; preview responses not in reports. Audit logs Enterprise.
