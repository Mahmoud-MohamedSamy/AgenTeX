# Distribution research (agent, help.zoho.com/portal/en/kb/survey/publish..., condensed)

Collector = one channel with own link + own response stream; many per survey. Publish tab -> Add New Collector. Groups: Public Access (Public Link [web link, social FB/X/LinkedIn/WhatsApp/Telegram share, embed iframe, popup, QR, hyperlink, Gmail, brand/white-label/custom URL], Offline Devices, Buy Responses), Private Audience (Email Invites by Zoho Survey, Email Invites by Zoho Services [Desk/CRM/Campaigns/Recruit/Billing/SalesIQ], Unique URL Generation, Invites by Other Services [Mailchimp, HubSpot, Zendesk, Shopify, Eventbrite, Salesforce, SendGrid, Klaviyo, Other Mail Client...], SMS Invites), Organization Invite (org members via Zoho Accounts/SAML). Manage: stop collecting, edit, delete, rename.
Embed: iframe; postMessage surveySize, moveScroll, zohosurvey_respondentStatus==='completed'; ?target=top shows thank-you in whole window.
Popup: pages all/chosen; prefill Data from URL Param/Cookie Value/Script Variable -> respondent/custom variable (hidden, in reports); timing: immediately, on zsShowPopup() call, after N seconds, exit intent, after scroll N%; position TL/TR/Center/BL/BR; height 350-700 fixed or min/max; minimize current page / keep minimized; close current page / do not show again; hide popup on custom end page; freeze page. Script after <body>.
QR: Get QR -> copy/download, all plans.
Email invites: Edit message (template header title/logo/alignment/colors, rich body, Insert Variable first/last/email/custom, Display Type Button "Begin Survey" or Question Embed, powered-by footer, save as template) -> Sender (From address, sender name; custom domain needs DKIM under Manage Portal > Domain Authentication) -> Send to specific contacts (CSV/XLS/manual: Email, Phone, First, Last, Variable1..6; each import a named group; NO dedup) or contacts based on triggers (trigger name, used by API/Zapier/Flow) -> Send: One-time (now/scheduled; triggers: immediately/after delay/at date/scheduled batches) or Recurring (daily/weekly/monthly, start date, time slots, interval, expiry non-stop/date/schedule count/collector response count/survey response count, skip weekends). Trigger expiry: non-stop, date, invitation count, collector resp count, survey resp count.
API: POST /api/v1/external-private/portals/{portalId}/departments/{deptId}/surveys/{surveyId}/collectors/{collectorId}/distributions/{distId}/email/sendinvitation, OAuth scope ZohoSurvey.invitation.CREATE, body contactsList[{emailAddress*,phoneNumber,firstName,lastName,variableOne..Six}], errors ACCESS_RESTRICTED, NEED_RECIPIENTS, DISTRIBUTION_DISABLED, INVITATION_LIMIT_REACHED, DAILY_EINVITE_LIMIT_REACHED, EINVITE_BOUNCE_RATE_EXCEEDED, EINVITE_COMPLAINT_RATE_EXCEEDED; 60 req/min/distribution.
Tracking: overview opened/yet to open/scheduled/bounced/unsubscribed; Invite history; recipients cols Email, Sent, Responded; filters All, No responses, Partial, Complete, Disqualified, Opened, Unopened, Unsubscribed, Bounced, Not sent, Failed. Reminders: to not-responded or partially-responded, one-time or recurring, only for email/SMS-distributed.
Other services: Identity Parameter (name + merge tag like ${Mobile}), Additional Parameters, Hashing (Manage Portal > Portal Setup > Hash Algorithm HMAC-SHA1/256/512 + secret, &hash=<hex>). Inline email: pick question -> Generate HTML.
CRM: related list Zoho Survey > Send Survey; email template Insert Survey Link; workflow alerts; mass email; Campaigns. Related list shows Sent By, Source (Individual/Mass Email/Workflow Alert/Campaigns/Taken by User), View Response or "Yet to respond", Take Survey. Write-back: Integration > Zoho CRM, module, map question->field, action Update/Add/Add-Update record, prefill mapped fields from CRM; record ID in URL.
Desk: Marketplace extension, profiles+departments, map up to 20 survey templates per dept, ticket widget insert link / send & close, Get Survey Link for email templates; links carry requester email, ticket id, agent name; Zoho Survey Report agent-based / contact-based.
Unique URL (CSV): upload CSV (UTF-8, <=1000 rows) -> Generate -> CSV downloaded with unique short URL per row; data saved as respondent variables; encrypted params prevent repeat.
SMS: providers Zoho SMS (DLT template, {Surveylink} mandatory), SMS Magic, Twilio, Clickatell; <=1000 numbers per invite; one-time/recurring; reminders.
Buy responses: no PII questions; up to 1000/collector; targeting country, region balancing, gender, age, income, marital, education, employment, industry; Calculate cost; survey locked after purchase.
Restrictions per collector: Survey End Date (author TZ); response limit; Collector quota (limit; on reach: close collector / terminate to over-quota page / continue as over-quota [+count]; notification recipients); survey + conditional quotas; Password (min 6, custom labels, messages <=255); IP allow/deny (equal to / in between / any one of); Response restriction one per email / per unique URL (parameter, block URLs without it) / per IP / per device (cookie) + edit mode (can't update / until complete / any time); CAPTCHA; Timer (page or survey, 5min-5h, auto-submit, disables Previous); closed survey page.
Partial = completed >=1 page without final submit (saved on Next). Save & Continue Later (Settings): resume email sender/subject/message/button label; response modification; from page 2; not with unique-response restrictions.
Offline: collector with admin password, kiosk mode, restart time, exit (inactivity) time, redirect home/first page, auto-upload; admin console upload all/edit/delete; browser cache storage; iPad/Android apps, guest login.
Metadata toggles: IP, User Agent, Email/First/Last, Geolocation (consent, page 1).
Plans: Free 1 user, 3 active surveys, 100 resp/survey, 10 invites/survey; Basic 3 surveys, 12k/yr, 2k invites/day, offline, unique URLs, CAPTCHA, quotas; Plus unlimited surveys, SMS, buy responses; Professional custom variables, conditional quota, white label, triggers, webhooks, CRM; Enterprise 3 users + add-on, 30k invites/day.
